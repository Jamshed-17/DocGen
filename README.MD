DocGen – Конструктор документов
Простая генерация грамот, дипломов и сертификатов

Функционал:
✅ Загрузка шаблонов (PNG/JPG)
✅ Расстановка текстовых/графических блоков
✅ Пакетная генерация из Excel/CSV
✅ Экспорт в PDF и PNG

Технологии:
Python (FastAPI), PostgreSQL, React

Для кого:
Учителя, организаторы мероприятий, HR.
